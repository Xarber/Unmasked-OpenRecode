# Contributing

Read AGENTS.md and docs/INDEX.md. Original contributions are AGPL-3.0-only. Preserve user privacy and existing behavior. Branch from testing, use a small feature branch and Conventional Commits, run relevant checks, update documentation and link any implemented Ideas. Open pull requests against testing. Do not promote directly to beta/main or change publication channels.

Include actual platform test evidence and untested areas. Use synthetic development fixtures, never real private transcripts. Avoid dependency upgrades that break Expo's bundled compatibility matrix. Report security issues privately; see SECURITY.md. Community access and public contribution channels are not activated while this repository remains private.
