# UADS traceability

The supplied sections 1–50 are the baseline. The registry groups related obligations by stable IDs and links each group to its authoritative sections and project evidence location. The groups cover all 50 sections. Individual subrequirements remain governed by the original text.

Run `npm run uads:validate` for schema and traceability validation. The Checks workflow also validates the production export and its bundled JavaScript budget. Pending group status means complete evidence has yet to be recorded. Review the [roadmap](ROADMAP.md) and [bootstrap report](reports/compliance/bootstrap.md) before promotion.
