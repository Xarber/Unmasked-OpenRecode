# Code of conduct

Be respectful, constructive and considerate of different experiences. Harassment, threats, discrimination, deliberate privacy violations and unwanted disclosure are unacceptable. Critique ideas and code without attacking people.

Maintainers may remove harmful contributions or restrict participation. Contact the repository owner privately through an existing channel to report an incident or appeal a decision. This project does not claim a staffed moderation team or a guaranteed response time. Never include private conversations or credentials in public reports.
