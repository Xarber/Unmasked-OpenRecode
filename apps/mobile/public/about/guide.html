THE PRACTICAL DETAILS

A place for the details.

This is an unreleased development version of Unmasked. These instructions describe the implemented account and messaging slice; they do not certify the entire product specification.

Use the web app

Open the application, create an account, verify the code sent by your server, and invite someone you know from Connections. Accepted contacts can start a conversation. Private invitations expire after 24 hours. An invitation alone does not grant messaging access.

For local development without SMTP, the loopback-only development mailbox contains verification codes. Never expose that mailbox or development database publicly.

Local setup & self-hosting

Source access is currently restricted. The owner is preparing to reconcile the existing public repository’s original history with the private development history; new application code is not being published there during this step.

With an authorized checkout, use Node 24 and npm 11:

npm ci
cp .env.example .env
npm run db:migrate
npm run dev

Development starts the API on localhost:3001 and Expo Web on localhost:8081. Persistent embedded PostgreSQL is development-only. X-Center is the default deployment infrastructure. Production requires real PostgreSQL, SMTP and same-site HTTPS origins, with isolated services, backups and tested rollback. Detailed procedures are in the repository’s docs/DEPLOYMENT.md and docs/platforms/XCENTER.md.

Generate the web application and its offline public shell:

npm run build:web
npm run preview

Docker self-hosting configuration is included. Before starting it, configure strong private credentials and valid HTTPS/API/mail settings. Never use production credentials in EXPO_PUBLIC_* variables.

iOS & Android availability

A shared Expo/React Native client targets both platforms. No downloadable IPA, APK or AAB is currently released. Native JavaScript export is not evidence of a successful device build, installation or physical-device test. 

npm run mobile
# With existing authorized platform toolchains:
cd apps/mobile
npx expo prebuild --platform ios
npx expo run:ios
npx expo prebuild --platform android
npx expo run:android

The prepared build matrix distinguishes an unsigned iOS device IPA, an iOS Simulator app, a signed universal Android APK and an Android App Bundle. Unsigned IPAs require signing; simulator apps are not device IPAs; AABs are not directly installable APKs. No store submission or public release destination is activated.

Privacy in plain language

This version does not implement end-to-end encryption. The server operator can read stored message text. TLS protects transport when properly configured; it is not E2EE. Use a trusted host, HTTPS and operator-managed storage/backup encryption before sharing real personal content.

Profiles start undiscoverable. Real names and photos are optional. Personal invitations enable private connections; under-18 accounts have restricted discovery and contact requirements. Age is self-declared, not verified. Unmasked Mode requires mutual acceptance; bio/status disclosures remain independently controlled and revocable.

Drafts, queued messages and recent history are stored locally without application-level encryption. Native refresh credentials use SecureStore; web refresh credentials use HttpOnly cookies. Signing out clears local account caches and pending drafts/outbox. Clearing only the read cache preserves drafts and queued messages. Developer Ideas are separate local notes and are not automatically sent to AI providers or synced to the repository.

Account deletion removes active profile/session/contact records and redacts authored message bodies, retaining tombstones in other participants’ shared history. Recipient screenshots/exports and operator backups cannot be retracted automatically. Reports contain only the content deliberately submitted by the reporter. Operator retention and appeal procedures must be established before public onboarding.

No advertising or third-party analytics is included. This is not a claim of legal certification or independently audited security.

What remains in development

Media/voice, push delivery, passkeys/provider login, full moderation/appeals, shared bookmarks, audited E2EE, automatic native updates, full offline-history replication and comprehensive physical-device validation are unfinished. Repository documentation records actual test evidence and release limitations.
